## Learnings - Task 03.03
_**Summarize your learnings (text or bullet points - whatever you prefer). What was challenging for you in this session? How did you challenge yourself?**_

In the first place I was able to get deeper in the types of tilings, the islamic patterns and the sacred geometry. I also learned how to create repetitive patterns in Unreal using the motion design plug-in. I was able to create my own forms, clone them and animate them using effectors. The use of textures was also part of the learning process along with the exploration of the form with the tools of the engine. 

It was very challenging to follow the tutorial, because the computer I am using from the University was slow sometimes and also the process was not as smooth as shown on the video. For example when installing the textures or when connecting the forms to the cloner I got a "is not static/cannot attach" error, so I needed to check online what the issue was. btw. [here](https://www.versluis.com/2024/08/how-to-fix-is-not-static-cannot-attach-in-unreal-engine/) is the link with the solution.

In spite of that I was able to solve the problems. I challenged myself by going beyond what the tutorial says and creating my own customized forms playing around with some of the tools that were not explained on that tutorial.
